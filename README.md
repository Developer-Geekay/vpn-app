# Geekay VPN Architecture

This repository contains the source code for the Geekay VPN system, which consists of a modern Android client and a Python FastAPI backend for managing WireGuard configurations.

## Project Structure
- `/android` - The Android client app built with Kotlin, Jetpack Compose, and Hilt. It uses the official WireGuard Android Tunnel library.
- `/backend` - The Python FastAPI backend that handles user authentication and dynamically provides WireGuard configurations.

---

## 🛠️ Backend Setup (Python)

### Prerequisites
- Python 3.9+
- `wireguard-tools` installed on your server (for production).

### Development Mode
In development, we use an in-memory mock database and return dummy WireGuard configurations for testing the app's UI and API flow.

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Create a virtual environment and install dependencies:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Run the development server with auto-reload:
   ```bash
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```
   *The API will be available at `http://localhost:8000`. You can view the interactive API docs at `http://localhost:8000/docs`.*

### Production Mode
For production, the backend should be run on the actual Linux server where WireGuard is installed. You will need to modify `main.py` to execute real `wg set` commands or update your `/etc/wireguard/wg0.conf` file dynamically.

1. Install a production-grade ASGI server like `gunicorn`:
   ```bash
   pip install gunicorn
   ```
2. Run the server using Gunicorn with Uvicorn workers:
   ```bash
   gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
   ```
3. **Security:** Ensure you put this API behind a reverse proxy (like Nginx) and secure it with SSL (HTTPS) so passwords and VPN keys are not intercepted.

## 📱 Android Setup (Kotlin)

### Prerequisites
- Android Studio (Iguana or newer recommended)
- Java 17

### Development Mode
When running the app on an emulator, the IP address `10.0.2.2` acts as `localhost` to your computer.

1. Open Android Studio and select **Open**. Choose the `/android` folder.
2. Wait for Gradle to sync dependencies.
3. If testing on a physical device, you must change `BASE_URL` in `android/app/src/main/kotlin/com/geekay/vpnapp/di/NetworkModule.kt` to your computer's local network IP (e.g., `http://192.168.1.X:8000/`).
4. Click the **Run** button (green play icon) to install the debug build on your emulator or device.

### Production Mode
Before publishing the app to the Play Store or distributing it:

1. **Update API URL:** In `NetworkModule.kt`, change the `BASE_URL` to your production backend URL (e.g., `https://api.yourvpn.com/`).
2. **Remove Cleartext Traffic:** If you enabled `usesCleartextTraffic` for local HTTP testing, remove it from `AndroidManifest.xml` (HTTPS is required for production).
3. **Generate Signed Bundle:** 
   - In Android Studio, go to `Build` -> `Generate Signed Bundle / APK`.
   - Create a new Keystore (keep the password safe!).
   - Select the `release` build variant and generate the `.aab` file.
4. **ProGuard:** The app has ProGuard enabled by default for release builds (`minifyEnabled true` or `false` depending on your setup in `build.gradle`). Ensure your WireGuard keys are kept secure.

## Note on WireGuard Integration
Currently, the `main.py` returns a hardcoded placeholder WireGuard configuration. To make the VPN actually connect to your server, you must replace the `interface_private_key`, `interface_address`, `peer_public_key`, and `peer_endpoint` in the `/config` endpoint of `main.py` with real keys generated by your WireGuard server.
